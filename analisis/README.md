# Analisis

Simpan:
- rekap hasil per laptop;
- rata-rata dan variasi pengulangan;
- grafik CPU, RAM, disk read, dan disk write;
- interpretasi hasil;
- keterbatasan penelitian.

Bandingkan Debian dan Windows secara berpasangan pada laptop yang sama. Analisis antar laptop dengan spesifikasi berbeda harus dipisahkan atau dikelompokkan menurut kelas hardware.
