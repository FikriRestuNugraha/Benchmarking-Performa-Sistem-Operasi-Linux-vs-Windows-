# Benchmark pada Windows 11

Folder ini untuk konfigurasi, catatan instalasi, dan instruksi pengujian di Windows native.

Simpan:
- versi Windows dan build;
- versi setiap tool benchmark;
- perintah/konfigurasi yang benar-benar dijalankan;
- log atau ringkasan hasil.

Catat dengan jelas jika suatu tool dijalankan melalui WSL atau lingkungan virtual. Jangan menyamakan hasil WSL/VM dengan pengujian native.
