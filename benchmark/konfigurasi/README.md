# Konfigurasi Benchmark

Simpan konfigurasi yang dipakai untuk pengujian, termasuk:
- workload CPU dan RAM;
- job file FIO;
- durasi dan ukuran data;
- jumlah worker/job;
- jumlah pengulangan;
- versi tool dan engine I/O.

Konfigurasi yang dibandingkan pada dua OS harus dibuat sama sejauh didukung oleh tool. Bila ada parameter/engine yang berbeda, tuliskan dan jelaskan dampaknya.
