# Script Pendukung (Opsional)

Folder ini dapat berisi script untuk:
- mengambil informasi sistem;
- menjalankan skenario benchmark yang sudah disepakati;
- memberi nama dan mengarsipkan hasil;
- mengolah file hasil.

Script otomatisasi bukan aplikasi benchmarking wajib menurut daftar output khusus Proyek 7. Pastikan script diuji dan dokumentasikan cara menjalankannya.
