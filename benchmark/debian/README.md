# Benchmark pada Debian

Folder ini untuk konfigurasi, catatan instalasi, dan instruksi pengujian di Debian native.

Simpan:
- versi Debian dan kernel;
- versi setiap tool benchmark;
- perintah yang benar-benar dijalankan;
- konfigurasi pengujian;
- log atau ringkasan hasil.

Jangan menyimpan file uji disk berukuran besar (`.bin`) ke GitHub.
