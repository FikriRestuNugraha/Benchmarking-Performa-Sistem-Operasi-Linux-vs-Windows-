# Data Mentah

Simpan hasil asli dari setiap pengujian tanpa mengubah isi file.

Pisahkan berdasarkan ID laptop, sistem operasi, komponen, dan pengulangan. Contoh:

```text
data/mentah/
└── LAPTOP-001/
    ├── Windows-11/
    │   ├── CPU/
    │   ├── RAM/
    │   └── Disk/
    └── Debian/
        ├── CPU/
        ├── RAM/
        └── Disk/
```

Sertakan log asli, JSON output, dan catatan konfigurasi. Jangan unggah file pribadi atau data sensitif.
